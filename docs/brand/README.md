# Brand files

Marks and compositions for All Together. Each SVG has a PNG beside it with the same name. Light files are shown on `#faf9f6` and dark files on `#171916`. The reasoning, sizes and rules are in [the motion and brand plan](../motion-brand-plan.md).

Recommended direction, "Drawn together":

- `mark.svg`, `mark-dark.svg`: the symbol, 32 grid, 2 stroke
- `favicon.svg`: the 16–32px version, 3 stroke, switches ink with the browser's colour scheme
- `wordmark.svg`, `wordmark-dark.svg`: "All Together", drawn monoline, 2.75 stroke
- `lockup.svg`, `lockup-dark.svg`: mark and wordmark, horizontal
- `mark-sizes.svg`: the mark at 16, 24, 32, 48 and 120px in both themes, beside the product's contribution bracket
- `stamp.svg`, `stamp-dark.svg`, `stamp-reclaimed.svg`: composition references for the confirmation stamp, drawn with the demo names. The running app should render this as HTML, and only after the mint confirms.
- `title-card.svg`: demo title card, 1920 × 1080
- `og-image.svg`: social image, 1200 × 630

Alternates that were not chosen:

- `alt-a-mark.svg`, `alt-a-lockup.svg`: "Bottom line", item rules over a double total rule
- `alt-b-mark.svg`, `alt-b-lockup.svg`: "Stub", a perforated receipt stub

The text in the stamp, title card and social image uses the system font stack, so it renders in whatever face the viewing machine provides. The mark and wordmark are plain strokes and render the same everywhere.
